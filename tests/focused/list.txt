# The focused tier's list (`scripts/focused`, docs/usage.md §Focused check).
#
# Two line kinds:
#   fixture <repo-relative path under assets/>
#       runs every corpus_test trial the harness generates for that file
#       (assets_*, vm_ok, artifact, pre_elaboration, verify, roundtrip, and
#       the origin/ownership groups), then the native differential its
#       conformance/pliron-parity.tsv row allows;
#   test <root test target> <exact test name>
#       runs that one named test.
#
# A fixture or test an overnight gate finds broken joins the list, under a
# dated `Gate failures` heading. A fixture that is red today stays off the
# list until the entry that owns it lands: a tier that starts red signals
# nothing. Such an entry stays here commented out, prefixed with the roadmap
# entry that owns it; restore it when that entry lands.
